# Character and class system

## Starting classes

The five starting classes are:

| Class | Role | Core identity |
|---|---|---|
| Knight | Frontline / defence | High HP and defence |
| Assassin | Burst / agility | Critical hits, speed and evasion |
| Mage | Magical damage | High mana and spell damage |
| Ranger | Ranged / precision | Consistent ranged damage and traps |
| Paladin | Support / frontline | Healing, shields and holy damage |

## Character archive card

Each collectible or named character may use a distinct card layout containing:

- Character artwork
- Archive number and rarity
- Character name, class and title
- Short lore description
- Combat attributes (HP, damage range, speed and other relevant stats)
- Unique abilities with trigger labels and effect descriptions
- Leader ability, if applicable
- Combat role tags

Characters do not need identical ability counts. Abilities should be distinctive and balanced.

## Class preview card

During first-time class selection, keep the preview focused:
- Artwork
- Class name and short identity line
- Short description
- Level 1 base stats
- Starting active skill(s)
- Passive trait
- Difficulty or role indicators
- Back and Confirm buttons

The preview must fit comfortably in a Telegram mobile chat. Avoid a full encyclopedia entry at character creation.

## Progression

Proposed progression:
- XP and character levels
- Attribute growth
- Skill unlocks
- Equipment bonuses
- Class milestones and awakening
- Appearance changes and cosmetics

Do not finalize damage formulas or level-up increments until combat simulations and playtesting are in place.
